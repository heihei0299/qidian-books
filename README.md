> **口径说明**：作者名单是本次题材筛选涉及的作者子集，不是起点历年白金作者的完整名册；作品也是相关代表作，不等于作者全部作品。白金称号会随平台制度及作者状态变化，历史获称与当前在籍不是同一概念。分类综合起点作品标签和作品主要设定；跨类作品按本表的主阅读类型归类。状态按 2026-10-06 可查到的起点页面/书单记录整理，连载状态可能变化。

## 复核说明

- 先列作者，再列小说分类；分类次序按要求，奇幻放在最后。
- 辰东没有遗漏：作者总表已列，作品分别见玄幻、仙侠、都市异能和奇幻边界条目。
- 《不死不灭》虽然完结，但起点历史介绍将其归为武侠幻想，故单独注明边界，不把它误称为典型西方奇幻。
- 完结重点用粗体标示；尚在连载的作品显式标注。目录只列本次核对的代表作，不能据此推断某作者其他作品的状态。
- 核对依据与可复查链接见文末“资料来源”。
